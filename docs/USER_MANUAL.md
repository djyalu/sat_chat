# 👥 SatChat 사용자 매뉴얼

## 시작하기

SatChat은 위성 영상을 활용한 해양 폐기물 모니터링 시스템입니다. 브라우저에서 바로 사용할 수 있으며, AI 기술을 통해 실시간으로 해양 환경을 분석합니다.

## 🌐 접속 방법

### 웹 브라우저 접속
1. **메인 URL**: https://djyalu.github.io/sat_chat/
2. **권장 브라우저**: Chrome, Firefox, Safari, Edge (최신 버전)
3. **모바일 지원**: 스마트폰 및 태블릿에서 사용 가능

### PWA 앱 설치 (권장)
1. 웹사이트 접속 후 브라우저 주소창 옆 **"설치"** 버튼 클릭
2. 또는 브라우저 메뉴 → **"홈 화면에 추가"** 선택
3. 데스크톱 앱처럼 사용 가능 (오프라인 지원)

### 기본 사용 흐름

#### Step 1: 지역 선택
1. **지역 버튼 클릭** 또는 **지도 마커 클릭**
2. 선택 가능한 지역:
   - **서해**: 인천, 태안 연안
   - **남해**: 거제도, 남해 연안  
   - **동해**: 울산, 포항 연안
   - **부산항**: 부산 항만 지역
   - **인천항**: 인천 항만 지역

#### Step 2: 분석 실행
1. 지역 선택 시 **자동으로 분석 시작**
2. 로딩 인디케이터 표시:
   ```
   ⏳ 서해 분석 중...
   🤖 AI 모델 실행
   📊 결과 생성
   ```

## 🔍 고급 기능

### 다중 지수 분석

#### 지원하는 지수들
1. **FDI (Floating Debris Index)**: 부유 폐기물 탐지
2. **NDWI (Normalized Difference Water Index)**: 수질 상태
3. **MCI (Marine Chlorophyll Index)**: 해양 생태계
4. **FAI (Floating Algae Index)**: 조류 번식
5. **탁도 (Turbidity)**: 물의 탁함 정도

#### 분석 모드 선택
```javascript
// 고급 분석 예시
{
  "region": "west_sea",
  "indices": ["FDI", "NDWI", "MCI"],
  "ml_detection": true,
  "confidence_threshold": 0.7
}
```

### AI 기반 객체 탐지

#### 탐지 가능한 객체
- **플라스틱 폐기물**: 병, 봉지, 용기류
- **기름 유출**: 선박 연료, 산업 폐수
- **어업 장비**: 폐그물, 부표, 로프
- **유기물**: 해조류, 나무 등
- **금속류**: 캔, 철제 폐기물

#### 탐지 결과 해석
```json
{
  "detections": [
    {
      "type": "plastic_debris",
      "confidence": 0.89,
      "location": [35.5, 126.3],
      "size_estimate": "medium"
    }
  ]
}
```

## 🔧 문제 해결

### 자주 묻는 질문 (FAQ)

#### Q1: 분석이 너무 느려요
**A**: 다음을 확인해주세요:
1. **네트워크 연결** 상태 확인
2. **브라우저 캐시** 초기화
3. **PWA 앱 재시작**
4. **다른 브라우저**에서 시도

#### Q2: 오프라인에서 사용할 수 있나요?
**A**: 네, 가능합니다:
1. **PWA 앱 설치** 필요
2. **최초 한 번** 온라인 접속 후
3. **기본 분석 기능** 오프라인 지원
4. **결과는 온라인 복구 시 동기화**

#### Q3: 모바일에서 잘 작동하지 않아요
**A**: 모바일 최적화 확인:
1. **최신 브라우저** 사용
2. **JavaScript 활성화** 확인
3. **충분한 메모리** 확보 (1GB+ 권장)
4. **Wi-Fi 연결** 권장

#### Q4: 분석 결과가 정확한가요?
**A**: AI 분석의 특성:
1. **85-95% 정확도** (지역별 차이)
2. **참고용**으로 활용 권장
3. **현장 검증**과 병행 사용
4. **지속적인 모델 개선** 중

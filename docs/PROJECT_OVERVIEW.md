# 🌊 SatChat - Marine Debris Monitoring System

## 프로젝트 개요

SatChat은 위성 영상과 AI/ML 기술을 활용한 해양 폐기물 모니터링 시스템입니다. 한국 연안 해역(서해, 남해, 동해)에 특화되어 개발되었으며, 실시간 해양 폐기물 탐지 및 분석 기능을 제공합니다.

## 🎯 주요 기능

### 핵심 기능
- **위성 데이터 수집**: Sentinel-2, KOMPSAT 등 다중 위성 데이터 통합
- **AI 기반 탐지**: 딥러닝을 활용한 해양 폐기물 자동 탐지
- **실시간 모니터링**: 한국 주요 해역의 실시간 상태 모니터링
- **다중 지수 분석**: FDI, NDWI, MCI, 탁도 등 다차원 분석
- **알림 시스템**: 위험도 기반 자동 알림 및 보고서 생성

### 한국 해역 특화
- **서해**: 높은 탁도, 연안 오염 모니터링
- **남해**: 항만 지역 집중 모니터링  
- **동해**: 심해 폐기물 탐지
- **항만 지역**: 부산항, 인천항 특화 모니터링

## 🏗️ 시스템 아키텍처

### Client-Heavy Architecture (현재 운영)
```
┌─────────────────────────────────────────────────────────────┐
│                    Client-Heavy PWA                         │
│  ┌─────────────────┐  ┌─────────────────┐  ┌──────────────┐ │
│  │   TensorFlow.js │  │  Interactive    │  │   Offline    │ │
│  │   ML Processing │  │   Dashboard     │  │   Capability │ │
│  └─────────────────┘  └─────────────────┘  └──────────────┘ │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│              Ultra-Minimal Proxy API                       │
│          (단순 데이터 중계 + CORS 처리)                     │
└─────────────────────────────────────────────────────────────┘
```

### 기술 스택
- **프론트엔드**: Progressive Web App (PWA)
- **ML 처리**: TensorFlow.js (클라이언트사이드)
- **맵핑**: Leaflet.js + OpenStreetMap
- **백엔드**: Ultra-minimal FastAPI proxy
- **배포**: Render (서버) + GitHub Pages (클라이언트)

## 📊 성능 특성

### 최적화 지표
- **클라이언트 처리**: 브라우저에서 직접 ML 추론
- **서버 부하**: 최소화 (데이터 중계만)
- **응답 속도**: <100ms (프록시 API)
- **오프라인 지원**: PWA 기반 오프라인 기능
- **메모리 사용**: 서버 <50MB, 클라이언트 적응적

## 🌍 사용 사례

### 주요 사용자
- **해양 환경 연구기관**: 연구 데이터 수집 및 분석
- **해양 경찰청**: 해양 오염 감시 및 단속

- **환경 모니터링**: 지속적인 해양 환경 상태 추적
- **정책 수립**: 데이터 기반 해양 환경 정책 결정
- **긴급 대응**: 대규모 해양 오염 사고 조기 감지
- **연구 지원**: 해양 과학 연구를 위한 데이터 제공
